# Pracownia promptów

Kurs prompt engineeringu dla studentów (LLM w pracy naukowej). Statyczna strona: otwórz `index.html` albo opublikuj przez GitHub Pages.

- `content.js` – treść lekcji (bloki: tekst, rozmowy z modelem, pytania kontrolne, zadania)
- `index.html` – układ i logika (postęp zapisywany w `localStorage`)
- `node test.js` – sprawdza poprawność treści
